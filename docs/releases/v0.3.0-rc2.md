# v0.3.0-rc2 | Developer Preview Beta

This is a source-available developer preview, not a stable release or a claim
of enterprise readiness. Commercial use still requires written permission.
No npm, PyPI or Homebrew package is being published.

## What changes

- RC2 supersedes RC1's Linux x86_64 compatibility limitation. RC1 required
  GLIBC_2.39; RC2 uses native Ubuntu 22.04 builds with a checked glibc 2.35
  ceiling for Linux x86_64 and ARM64. Built and extracted binaries are checked.
  RC1 and its tag/assets are unchanged.
- rustls 0.23.45 addresses
  [RUSTSEC-2026-0285](https://rustsec.org/advisories/RUSTSEC-2026-0285.html).
- Capture-health gates, inspector redaction/consent parity, conflict-aware
  setup undo/recovery and explicit database propagation protect local evidence.
- Bounded recording queues and storage/artifact-write protections report
  incomplete captures rather than treating them as trustworthy baselines.
- Stdio cancellation uses an explicit terminal status. Diff and golden-assert
  JSON now emit schema version 4; archived v3 schemas remain unchanged.
- Optional bounded schema-change explanations are advisory only.
- Default archives contain the core workflow. Labs and lexical semantic
  commands require explicit feature builds.

## Install and verify

Install this preview explicitly with MCPTRACER_VERSION=v0.3.0-rc2.
See the repository's installation guide for platform commands and
GitHub attestation verification. Verify downloaded archives against
SHA256SUMS.txt. Checksums establish integrity, not authorship; provenance
verification is a separate check.

The release covers Linux x86_64/ARM64, macOS x86_64/ARM64 and Windows x86_64.
The tagged public commit's export manifest identifies its reviewed private
source revision. Release assets include packaged licensing and a CycloneDX SBOM.

## Remaining limitations

HTTP cancellation persistence/replay is design-only. MCP current-protocol
support is partial, not full conformance. Team/registry implementation is
excluded. Recorded hashes are not signatures. Queue pressure can drop capture
messages while preserving forwarding; unhealthy captures must fail assurance.
Earlier intermittent HTTP/test-cleanup/deadline failures have unresolved causes.
Synthetic fixtures and short benchmarks do not establish sustained production
reliability, independent editor onboarding or outside consumer-CI adoption.
