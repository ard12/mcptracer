# v0.3.0-rc3 | Developer Preview Beta

This is a source-available developer preview, not stable or a claim of
enterprise readiness. Commercial use requires written permission.
No npm, PyPI, crates.io or Homebrew package is being published.

## What changes from RC2

- Schema-aware redaction requires a matched `tools/list` request. Sensitive
  runtime extensions are masked without destroying schema property names.
  Recording and artifact validation use the same request context.
- HTTP recording bounds live writers, active capture exchanges and idle
  lifetime. Traffic beyond recording admission still forwards, while omissions
  and incomplete evidence are reported instead of silently trusted.
- SSE framing bounds physical lines and rejects undelimited events at EOF.
  Partial or failed captures cannot be promoted into complete evidence.
- The inspector uses indexed exchange lookup and lazy payload formatting,
  reports shared capture health and clears credentials after authentication
  failures.
- Stdio startup failures explicitly terminate and reap the child process.
  Wrappers require explicit authority to select local development binaries.
- CI checks isolated source installation and the first-use tutorial on three
  operating systems; packaging rehearsal exercises the extracted default
  binaries on all five supported targets.

RC3 retains RC2's native Ubuntu 22.04 / glibc 2.35 Linux compatibility floor.
RC1 and RC2 tags and assets are preserved. The old RC1 x86_64 archive still
requires GLIBC_2.39; use RC3 for the latest preview fixes.

## Install and verify

Pin the preview explicitly with `MCPTRACER_VERSION=v0.3.0-rc3`.
See the [installation guide](../../docs-site/src/installation.md) for platform
commands. Until RC3 assets are available, build the reviewed source revision.

Verify archives against `SHA256SUMS.txt` and separately verify GitHub build
provenance using `gh attestation verify <archive> --repo ard12/mcptracer`.
The release includes packaged licensing and a CycloneDX SBOM.
The tagged public commit's `OSS_EXPORT_MANIFEST.json` identifies the reviewed
private source revision.

Default archives contain the core workflow. Labs and lexical semantic search
remain opt-in source builds, not default release features.

## Compatibility and remaining limits

Older artifacts accepted by shape-only schema validation may now be refused.
Diff and golden-assert reports remain schema version 4; archived v3 schemas
remain unchanged.

Full independent security audit, real-browser acceptance and sustained-load
evidence remain incomplete. MCP current-protocol support is partial, not full
conformance. HTTP cancellation persistence/replay remains design-only.
Team/registry implementation is excluded. Hashes are not signatures.
Queue pressure can omit capture while preserving forwarding; incomplete
captures must fail assurance. This preview does not establish production
reliability or enterprise readiness.
