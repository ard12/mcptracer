# MCPTracer Public Source Export

This directory was generated from an authoritative committed source revision.
`OSS_EXPORT_MANIFEST.json` records that revision, this export policy's hash,
the omitted reserved paths, and SHA-256 hashes for every other exported file.
The manifest itself is not self-hashed because a recursive self-hash cannot be
stable.

with the authoritative source; make changes in the authoritative repository and
regenerate an export from a committed ref.
