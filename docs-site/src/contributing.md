# Contributing

Bug reproductions, clearer documentation, focused fixes, and compatibility
cases are welcome. You can participate entirely through the public repository.

The [contribution guide](https://github.com/ard12/mcptracer/blob/main/CONTRIBUTING.md)
covers setup, crate ownership, checks, and how patches are integrated.
See [About MCPTracer](https://github.com/ard12/mcptracer/blob/main/ABOUT.md)
for the maintainer and contact section.

Report vulnerabilities through the private route in the
[security policy](https://github.com/ard12/mcptracer/blob/main/SECURITY.md).
